# The Canon of Dhar

The Canon is the forward-looking specification: what Dhar is to become. It contains no status; what exists today is in
[../reports/PROGRESS.md](../reports/PROGRESS.md).

## How the Canon changes

Master Index §10: a ratified document changes only through a new minor or major version, with a one-line reason in its
revision log. The amendments below are therefore issued as new versions (v1.1) of the documents they touch. "One rule, one
home" (§3.4) decides where each rule goes: keyword semantics in Spec1, a security guarantee in Tempering Dhar, a licensing
decision in The Hallmark of Dhar, and everywhere else links back.
